# Real-Time Chat Application Backend

Backend service for a real-time chat application built with Node.js, Express.js, WebSockets, and PostgreSQL. The server manages authentication, real-time communication, user sessions, and message persistence.

## Related Repositories

Frontend Repository:
https://github.com/Ukullayappa/chatapp-frontend

https://github.com/Ukullayappa/chatapp-backend

## Features

* Real-Time Communication
* WebSocket Server
* User Authentication
* Session Management
* Persistent Message Storage
* Online User Tracking
* REST API Endpoints
* PostgreSQL Database Integration

## Installation

### Clone Repository

```bash
git clone https://github.com/Ukullayappa/chatapp-backend.git

cd chatapp-backend
```

### Install Dependencies

```bash
npm install
```

### Start Server

```bash
npm start
```
